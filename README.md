# Unit Management System

A modern Personnel & Task Management System developed for military unit administration.

## Features

- Personnel Management
- Company-wise Access Control
- Task Assignment & Tracking
- Admin Dashboard
- Company Commander Dashboard
- Role-based Authentication
- Responsive UI
- Built with Next.js & TypeScript

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase (Upcoming)
